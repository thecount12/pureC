I wrote this book to learn C. I work in Plan 9, but  I  want
you  to learn the language, not my operating system. So here
is the one rule.

_ ________, ___ _ ________

Lisp got there first  in  my  head.  Abelson  and  Sussman's
Interpretation  _________and  (second  edition), and the MIT
lectures that go with it, made a program feel like a  spell:
a  small  text  that,  when  you run it, does a thing in the
machine. People call that the wizard book.  Sorcerer  Linux,
which  later  became  Source  Mage, used the same word for a
package you compile. I still like that. A grimoire is a book
you work from.

This one is C. The listings are the spells. You  copy  them,
you compile, they run or the compiler tells you why. We keep
one working,  ______, instead of a new demon every page. The
same  craft  lives on Plan 9 at  ___________.____.  Here the
printed dialect stays POSIX so you can learn  the  language.
The names in the listings are not magic. They are C.

If a listing and a  ._ file disagree, trust the    ._  file,

C skill is not syntax. It is a few habits: initialize  every
variable, check  ______ and  _____, pass a length with every
array, and keep one dialect in a file.  The rest of the book
